# ⚡ Extension Chrome SkibidiMP3

Cette extension vous permet de télécharger vos musiques et vidéos directement depuis Chrome en 1 clic (YouTube, Spotify, SoundCloud, etc.), avec synchronisation automatique de votre historique avec votre compte SkibidiMP3.

---

## 🚀 Installation Rapide (Sans Chrome Web Store)

1. Ouvrez **Google Chrome** (ou Brave, Edge, Opera, etc.).
2. Accédez à la page des extensions en tapant `chrome://extensions` dans la barre d'adresse.
3. Activez le **« Mode développeur »** (interrupteur en haut à droite).
4. Cliquez sur le bouton **« Charger l'extension non empaquetée »** (*Load unpacked*).
5. Sélectionnez le dossier `chrome-extension` situé dans votre projet :
   `c:\Users\Sébastien\Desktop\work\dev\youtubemp3booste\chrome-extension`
6. L'extension apparaît immédiatement dans votre barre d'outils Chrome ! ⚡

---

## 🎯 Fonctionnalités & Utilisation

### 1. Bouton direct sur YouTube
* Rendez-vous sur n'importe quelle vidéo ou Short YouTube.
* Un bouton violet/cyan **« ⚡ MP3 Boosté »** apparaît directement sous la vidéo à côté des boutons Like/Partager.
* Cliquez dessus pour lancer la conversion instantanée et télécharger le fichier en 320 kbps.

### 2. Popup de l'extension
* **Onglet Convertir :** Détecte automatiquement la vidéo de l'onglet ouvert. Permet de choisir le format (MP3, FLAC, WAV, MP4), la qualité (320k, 256k...), le boost de volume (+2 dB, +4 dB...) et d'éditer les tags ID3 (titre / artiste).
* **Onglet Historique :** Affiche la liste de tous vos téléchargements enregistrés sur votre compte. Vous pouvez réécouter/retélécharger un titre ou le supprimer en 1 clic.
* **Onglet Compte :** Connectez-vous avec votre compte utilisateur pour synchroniser l'historique avec le site, ou modifiez l'URL de votre serveur (par exemple pour pointer sur votre VPS `https://...`).
